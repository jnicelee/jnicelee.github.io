# Janice Lee Personal Website

A static personal website ready for GitHub Pages. Edit `index.html` to update
the bio, project cards, and links.

## Publish on GitHub Pages

1. Create a new GitHub repository named `jnicelee.github.io`.
2. Upload or push every file in this folder to that repository.
3. In GitHub, open **Settings > Pages**.
4. Set **Source** to `Deploy from a branch`, choose `main`, and choose `/ (root)`.
5. Visit `https://jnicelee.github.io` after GitHub finishes deploying.

## Files

- `index.html`: page content
- `styles.css`: copied from `beaverseven/Portfolio` with permission, with a
  small compatibility override block at the end for this portfolio's content
- `script.js`: current year and sticky header behavior
- `assets/hero-workspace.png`: generated hero image
- `sal.css` / `sal.js`: scroll reveal animation files pulled from
  `beaverseven/Portfolio`
